Generador de Fichas

Carga primero una configuración de cliente, después el Excel de procedimientos

1

Selecciona la configuración del cliente

Ve al Configurador (botón en el header) para crear o cargar la configuración de un cliente. Define las columnas del Excel, los bloques visibles y la plantilla HTML de salida.

Puedes tener tantas configuraciones como clientes
2

Carga el Excel

Arrastra o selecciona el fichero .xlsx, .xls o .ods. La herramienta detecta automáticamente los procedimientos según la configuración activa.

El Excel puede tener tantas columnas como necesites
3

Edita y descarga

Selecciona procedimientos, edita el contenido de los bloques con formato rico y descarga los HTML listos para la sede electrónica.

Las ediciones se guardan si cambias de procedimiento

 Plantilla HTML de salida

        
Define cómo se genera el HTML de cada ficha. Usa los marcadores indicados para que la herramienta inserte el contenido dinámico.

        

          
          
Marcadores disponibles: {{TITLE}} (título del procedimiento), {{BLOCKS}} (todos los bloques del acordeón generados), {{CODE}} (código del procedimiento).

        


        
        

        
        

        
        
        Marcadores del bloque: {{BLOCK_ID}} (número), {{BLOCK_LABEL}} (etiqueta), {{BLOCK_CONTENT}} (contenido), {{FIRST_CLASS}} ('' o 'collapsed'), {{FIRST_SHOW}} ('' o ' show')
